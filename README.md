# Vibe Lab 🧪📱

Labo d'exploration mobile : UI simple, widgets, signaux (event-bus), sauvegarde/chargement de fichiers, mini-jeu.
Développé avec **Mistral Vibe**, 100 % depuis un téléphone Android.

## Structure (aucun build nécessaire)
- `index.html` — app complète (React + Tailwind via CDN)
- `manifest.webmanifest` — PWA installable sur Android
- `sw.js` — mode hors-ligne
- `icon.svg` — icône

## Déploiement GitHub Pages
Settings → Pages → Branch `main`, `/ (root)` → Save → https://tabit0u.github.io/vibe-lab/
